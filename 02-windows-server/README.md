### Commands Used  

```text
hostname  
whoami
ipconfig  
winver 
Get-Service  
netstat -ano
```  
  
### Key Concepts  
  
Windows Server is designed to provide centralized services and resources  
to other systems and users.  
  
Server roles define major jobs that a Windows Server performs, such as  
DNS, DHCP, file services, and Active Directory Domain Services.  
  
A virtual machine behaves like an independent computer even though it  
shares physical resources with the host computer.  
  
### What I Learned  
  
Installing Windows Server alone does not automatically make the machine  
a Domain Controller or DNS server. Server roles must be installed and  
configured based on the purpose of the server.

### Commands Used  

```text
hostname   
ipconfig /all
Get-Service  
netstat -ano
```  
  
### Key Concepts  
  
Servers should use clear, predictable naming conventions so administrators  
can easily identify their purpose.  
  
Servers commonly use static IP addresses because other systems and services  
need to locate them reliably.  
  
Windows services are background applications that provide operating system  
and application functionality.  
  
Common startup types include:  
  
- Automatic  
- Manual  
- Disabled  
  
### Troubleshooting Concept  
  
A server can be reachable on the network while a specific application is  
unavailable because the required service is stopped, the expected port is  
not listening, or a firewall is blocking access.  
  
### What I Learned  
  
Server availability and service availability are not the same thing.  
Troubleshooting should verify both the server's network connectivity and  
the state of the specific service being used.

### Commands Used  

```text
eventvwr.msc 
Get-WinEvent -LogName System -MaxEvents 20  
Get-WinEvent -LogName Application -MaxEvents 20 
```

### Key Concepts  
  
Windows logs record operating system, application, and security events.  
  
The Application log contains events generated by applications.  
  
The System log contains events generated by Windows services, drivers,  
and operating system components.  
  
The Security log contains security and authentication-related events.  
  
Event logs should be reviewed around the time a reported problem occurred.  
  
### Troubleshooting Concept  
  
Logs provide evidence that can help determine what happened before or  
during a failure.  
  
For example, if a service unexpectedly stops, Event Viewer may contain  
related events that help identify the cause.  
  
### What I Learned  
  
Troubleshooting should not rely only on symptoms. Event logs provide  
historical information that helps correlate a reported problem with  
system or application activity.

### Commands Used  

```text

Get-DnsClientServerAddress

nslookup
```  
  
### Key Concepts  
  
Servers usually use predictable IP addresses so clients and services can  
reliably locate them.  
  
DHCP automatically provides network settings, while static addressing is  
manually configured.

Incorrect gateway settings can prevent access to other networks.  
  
Incorrect DNS settings can allow IP connectivity while causing hostname  
resolution failures.  
  
### What I Learned  
  
A server's hostname identifies what the server is, while its IP address  
identifies where the server can be reached on the network.  
  
Network changes should be made one at a time and verified before and  
after configuration changes.
