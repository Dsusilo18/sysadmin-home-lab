# System Administrator Home Lab

A hands-on Windows and Linux administration lab built to develop
practical system administration and troubleshooting skills.

## Lab Environment

Host:
- Windows 10
- 16 GB RAM

Planned / Current Virtual Machines:
- Windows Server
- Windows Client
- Ubuntu Server

## Technologies Covered

- TCP/IP Networking
- Windows Server
- Active Directory
- DNS
- DHCP
- Group Policy
- File Permissions
- PowerShell
- Linux Administration
- Troubleshooting
